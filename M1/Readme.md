## Project Overview

This project explores the use of **Probabilistic Graphical Models (PGMs)** for interpretable lung cancer risk prediction.

The aim is to model dependencies among demographic, behavioral, and symptomatic risk factors while supporting probabilistic inference under partial evidence.

## Milestone 1 — Proposal & Scoping

In this milestone, we:

* Defined the **problem statement and project scope**
* Selected the **Lung Cancer Survey Dataset**
* Proposed a **Conditional Independence Graph** using Graphical Lasso
* Proposed a **Bayesian Network** using score-based structure learning
* Defined probabilistic inference queries for lung cancer risk
* Selected **Logistic Regression** and **Naive Bayes** as baseline models
* Studied **Neural Graphical Models (NGM)** as the SOTA reference
* Defined evaluation criteria across **Representation, Inference, and Learning**
* Established the experimental plan for subsequent milestones

> **Note:** The graphical models and experiments described above are part of the proposed methodology for future milestones. M1 focuses on problem formulation, literature study, methodology design, and project planning.
